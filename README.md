# vlsi_flows
RTL - GDS-II Tapeout flows 
We use various EDA tools from Companies like Cadence/Synopsys/Siemens/OpenRoad right from synthesizing the RTL to generating Final GDS - II (GDS-II (Graphic Data System II) is the industry-standard binary file format for exchanging integrated circuit (IC) layout data, serving as the blueprint for chip manufacturing by storing geometric shapes, text, and hierarchical cell information for all layers.)
We have Readme for all the flows to help users run various stages in creating Final GDS - II output.
